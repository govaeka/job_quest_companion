# Job Quest Companion

This is the tool I use to keep track of job applications, resume versions, personal notes etc.

### As it stands, it is merely a database that I query and update by using SQLc on the command line.
Tools used: Go, SQLc, PostgreSQL, Goose

### I want to gradually expand this as time allows.

1. add HTML Frontend using HTTP requests
2. add htmx
3. add an API to allow other frontends
4. add text analysis for resumes and cover letters
5. add an analytics dashboard
6. ...
