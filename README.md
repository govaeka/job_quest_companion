# Job Quest Companion

This is the tool I use to keep track of job applications, resume versions, personal notes etc.

### As it stands, it is merely a database (normalized to 3NF) that I query and update by using SQLc on the command line.
Tools used: Go, SQLc, PostgreSQL, Goose

### I want to gradually expand this as time allows.

1. add an API to allow for multiple Frontends
2. add a Dashboard-style Frontend with HTML and htmx
3. add text analysis for resumes and cover letters
4. add an analytics dashboard
5. ...
